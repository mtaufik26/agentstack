This project uses specialized AI skills.

Before starting any task:

1. Read PROJECT_CONTEXT.md completely.

3. Understand the product vision.
4. Understand the target audience.
5. Understand the business goals.

PROJECT_CONTEXT.md is the primary source of truth.

# Development Philosophy

The goal is not simply to generate code.

The goal is to create a production-quality SaaS landing page.

Every decision should prioritize:

* User Experience
* Conversion
* Maintainability
* Scalability
* Performance

* Premium

# Mobile First

Traffic Distribution:

* Mobile: 60%
* Desktop: 30%
* Tablet: 10%

Mobile users are the primary audience.

Every layout decision should prioritize mobile experience.

# Performance Rules

Optimize for:

* Fast loading
* Mobile devices
* Core Web Vitals

Avoid:

* Unnecessary libraries
* Excessive animations
* Large component files

---

# Component Rules

Use:

* Reusable components
* Clear naming
* Scalable architecture

Avoid:

* Hardcoded content
* Duplicate code
* Massive components

# Content Rules

All content should be generated using PROJECT_CONTEXT.md.

Generated content should include:

* Features
* Benefits
* FAQs
* Testimonials
* Statistics
* Pricing

---

# Final Quality Check

Before completing any task ask:

1. Would a senior designer approve this?
2. Would a senior frontend engineer approve this?
3. Is this maintainable?
4. Is this scalable?
5. Is this mobile friendly?
6. Is this production ready?

If the answer is no, improve it before responding.

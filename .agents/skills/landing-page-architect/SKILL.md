# Landing Page Architect

## Goal

Create scalable and maintainable landing page architecture.

## Stack

* Next.js 15
* TypeScript
* Tailwind CSS v4
* shadcn/ui

## Responsibilities

* Define folder structure
* Define page structure
* Define section order
* Define data structure
* Define reusable architecture

## Preferred Structure

Navbar
Hero
Logo Cloud
Features
Benefits
Statistics
How It Works
Testimonials
FAQ
CTA
Footer

## Rules

Never place all code inside page.tsx.

Separate sections into reusable components.

Keep architecture scalable.

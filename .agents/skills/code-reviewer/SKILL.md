# Code Reviewer

## Goal

Maintain production-quality code.

## Review Criteria

* Readability
* Maintainability
* Scalability
* Accessibility
* Performance

## Check For

* Duplicate code
* Poor naming
* Large components
* Unused imports
* Bad architecture

## Feedback Style

Always explain:

* What is wrong
* Why it is wrong
* How to improve it

Provide actionable recommendations.
